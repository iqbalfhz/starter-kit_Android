## Cara Pakai Starter Kit Flutter

1. Clone repo ini
2. Ganti nama package di pubspec.yaml
3. Ubah baseUrl di `utils/constants.dart`
4. Jalankan `flutter pub get`
5. Jalankan app
6. Selesai
7. Happy coding :)
8. Jangan lupa bintang repo ini ⭐
